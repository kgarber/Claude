SumPath 2
Speed mode. 30 seconds. Infinite paths.

How to Play SumPath 2

Score as many paths as you can in 30 seconds. Each completed path gives you a new target to chase.

Movement

  • Tap any cell to start a new path — start from anywhere
  • Move in any of 4 directions: up, down, left, or right
  • Each new cell must be adjacent to the last one
  • Tap a cell already in your path to backtrack to that point
  • Tap a non-adjacent cell to reset and start a fresh path

Scoring

  • When your path sum exactly matches the target, it auto-accepts
  • Each accepted path = +1 combo and +10 seconds added to the clock
  • A new random target appears and the grid refreshes
  • Keep going — the better you play, the more time you earn

Tips

  • Move fast — the timer never stops
  • If you overshoot, backtrack instead of starting over
  • Small targets are quicker; big targets need longer paths
  • Your best score is saved locally
